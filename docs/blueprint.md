# **App Name**: Khurmah Deals

## Core Features:

- Browse Offers: Allow users to browse local deals and discounts in Khurmah.
- User Authentication: Implement role-based authentication for visitors, store owners, and admins.
- Store Owner Dashboard: Enable store owners to manage their ads, view performance metrics, and communicate with customers.
- Admin Dashboard: Provide admins with tools to review ads, manage users, and oversee categories.
- Ad Management: Allow store owners to create, edit, and manage their ads.
- Payment Gateway: Integrate a secure payment gateway for ad fees.
- AI Ad Suggester: AI tool helps store owners to craft high-impact, engaging and unique advertisement copy to attract more customers. 

## Style Guidelines:

- Primary color: A vibrant sandy beige (#F2E7D5) evoking the desert landscape.
- Background color: Light tan (#F9F6F2), a desaturated version of the primary for a calming effect.
- Accent color: Muted brick red (#A3795F), analogous to the primary, adding warmth.
- Body and headline font: 'PT Sans' for headlines and body text: its slightly rounded letters combines modernity with a touch of approachability.
- Use clear, intuitive icons representing deal categories, user roles, and admin functions.
- A clean, card-based layout emphasizing the deals available; should feel open and modern.
- Subtle transitions and loading animations to create a smooth browsing experience.
